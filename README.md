# 📚 Biblioteca Java

Projeto desenvolvido em Java com o objetivo de praticar e aprimorar conceitos de Programação Orientada a Objetos (POO).

O projeto representa um sistema simples de biblioteca, com funcionalidades relacionadas ao cadastro de livros, catálogo e clientes.

## 🚀 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Git
- GitHub

## 📌 Conceitos praticados

- Programação Orientada a Objetos (POO)
- Classes e objetos
- Encapsulamento
- Herança
- Getters e Setters
- ArrayList
- Listas e coleções
- Estruturas de repetição e condicionais
- Entrada de dados com Scanner
- Organização de classes em pacotes
